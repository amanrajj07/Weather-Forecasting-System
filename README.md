ESP32 Based Weather Forecasting System

Project Overview

This project is an ESP32-based weather monitoring system developed using Arduino IDE. It uses different sensors to monitor environmental conditions.

Hardware Components

* ESP32 Development Board
* DHT11 Humidity Sensor
* LM35 Temperature Sensor
* Rain Sensor Module
* Connecting Wires
* Breadboard

Working Principle

* DHT11 measures humidity.
* LM35 measures temperature.
* Rain sensor detects the presence of rain.
* ESP32 processes the sensor readings.

Software Requirements

* Arduino IDE
* ESP32 Board Support Package

Features

* Temperature monitoring
* Humidity monitoring
* Rain detection
* Real-time sensor data processing

Project Type

Major Project – Diploma in Electrical Engineering
